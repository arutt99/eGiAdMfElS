# Table artwork

`pirate-table.webp` was created with the built-in image generation tool, then encoded as WebP at quality 85 for local web delivery. It is bundled with the game and requires no external request. The reference screenshots informed the interface direction; the generated characters are new artwork.

Final generation prompt:

Use case: stylized-concept. Asset type: background artwork for a playable pirate card game, landscape 1536x1024. Create a rich hand-painted 2D classic pirate board-game scene. Dark weathered horizontal ship-deck wooden planks fill the whole image, warm brown charcoal palette, subtle worn old map engraving and brass flecks, strong dark vignette. An original charismatic female pirate duelist in a black tricorn with ivory lace edging, auburn flowing hair, white shirt and dark leather waistcoat holding a dagger occupies ONLY the lower LEFT corner, her bust rises from bottom edge and fills leftmost 25% and bottom 44%. An original sinister grinning male pirate captain with dark beard, black gold-trimmed tricorn, red cravat and a hook occupies ONLY upper RIGHT corner, cropped bust emerging from right edge filling rightmost 24% and top 42%. Illustrated painted characters with expressive faces, bold silhouette, golden highlights, detailed antique adventure game aesthetic. Keep middle 50% across the entire image EMPTY dark wooden planks suitable for readable live game UI. A few piles of antique gold coins at upper left and lower right extreme corners. NO letters, no text, no numbers, no UI, no buttons, no cards, no borders. This is a production background art asset; do not draw a device or screenshot.

# Card artwork

The card set uses original generated illustrations bundled under `cards/`. There is one reusable illustration for each of the ten suits, so all six cards in a suit share the same art while their value remains live HTML text. `back.jpg` is the symmetrical illustrated back used by the clickable draw pile. The source renders were generated with the built-in image generation tool and resized to 640px JPEGs at quality 84 for browser delivery.

Shared visual direction for the suit art:

Use case: stylized-concept. Asset type: square reusable suit illustration for a pirate card game. Richly painted 2D fantasy board-game illustration with antique nautical engraving influence, tactile brushwork, bold readable silhouette, deep navy and charcoal teal, aged brass highlights, moonlit stormy sea atmosphere. Center one clear suit focal subject in a square composition with generous edge breathing room. No text, numerals, letters, UI, border, watermark, logos, or extra characters.

Suit subjects: Anchor — weathered iron anchor in moonlit seawater; Hook — aged brass grappling hook on frayed rope; Cannon — antique ship cannon on a dark deck; Key — ornate brass key on weathered sailcloth; Chest — open treasure chest with coins; Map — rolled nautical chart with compass and abstract coastline; Oracle — luminous eye inside a crystal orb; Sword — pirate cutlass on a wet deck; Kraken — colossal shadowy kraken in black-green waves; Mermaid — original elegant mermaid rising from moonlit waves.

Deck-back direction:

Use case: stylized-concept. Asset type: square illustrated back for a pirate card deck. Symmetrical full-bleed design with a centered antique compass rose, crossed cutlasses, curling rope knots, wave motifs, and an ornamental frame in midnight navy, charcoal teal, aged brass, and muted crimson. No text, numerals, letters, UI, watermark, logos, asymmetry, or extra characters.
